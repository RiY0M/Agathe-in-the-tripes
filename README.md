# Comment jouer au jeu :

__Méthode 1 : Jouer en ligne__

Connectez-vous au VPN de l'IUT et allez à cette adresse :
https://devweb.iutmetz.univ-lorraine.fr/~schandel2u/SAE501/HTML/index.HTML

__Méthode 2 : Installer le jeu__

Pour ce faire, clonez le projet ou téléchargez le zip du main.
Pour faire fonctionner la base de données, vous devez être connecté au VPN de l'IUT

__Peu importe la méthode choisie, suivez ensuite ces étapes :__
Créez vous un compte pour enregistrez votre score (facultatif)
Appuyez ensuite sur le bouton "Nouvelle partie" ou "Continuer partie" si vous êtes connecté et que vous aviez une partie en cours
Jouez et profitez !
